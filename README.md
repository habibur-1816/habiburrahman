# GFX HABIBUR Portfolio

A fast, responsive, SEO-ready static portfolio for GitHub Pages.

## Edit first
1. Replace `YOUR-USERNAME` in `index.html`, `robots.txt`, and `sitemap.xml`.
2. Replace `YOUR-EMAIL@example.com`.
3. Replace Behance/LinkedIn/YouTube URLs.
4. Replace project placeholders with your real portfolio images and links.
5. Replace the favicon if you have your final logo.

## Local preview
Open `index.html` directly, or use VS Code + Live Server.

## Free hosting
Recommended: GitHub Pages. Create a public repository named `<habibur-1816>.github.io](https://github.com/habibur-1816/habiburrahman.git)`, upload these files, then enable Pages from Settings → Pages.

## SEO checklist
- Use one clear H1.
- Give every real project an accurate title and descriptive image alt text.
- Add a unique page title and meta description.
- Keep images compressed (WebP/AVIF where practical).
- Submit `sitemap.xml` in Google Search Console.
- Connect your professional profiles and keep your NAP/contact details consistent.
- Publish useful project case studies over time.

## Important
A free `github.io` address is free. A custom `.com` domain is normally a paid registration; GitHub Pages can host it once you own the domain.
